# Bard for iPhone

Native SwiftUI listening companion sharing the local `WispCore` package. iOS 17 or later; scheme `WispIOS`; visible name Bard. Preserve bundle ID `com.briggskellogg.wisp.ios`, existing storage/bookmark formats, preference migration, and the registered App Store Connect record. Internal Wisp names are intentional compatibility identifiers.

Run scripts from the repository root:

```sh
bash iOS/scripts/generate-project.sh
bash iOS/scripts/build-simulator.sh
bash iOS/scripts/build-device-unsigned.sh
```

Generation requires XcodeGen 2.44 or newer. Builds use `iOS/.build` unless `WISP_IOS_BUILD_DIR` supplies another local build directory. The simulator destination defaults to a generic device; `WISP_IOS_DESTINATION` can select a specific destination. These commands do not install or upload an app.

## Signing and release

Set `WISP_TEAM_ID` to the verified personal Apple team before `archive.sh`, `export-testflight.sh`, or `upload-testflight.sh`. Set `WISP_ALLOW_PROVISIONING_UPDATES=1` only for authorized Xcode-managed signing. Supply fresh output paths; preserve existing archive/export evidence. Never copy a work-machine keychain or include signing credentials in source.

`export-testflight.sh` produces a local distribution export. `upload-testflight.sh` uploads an authorized frozen build but does not prove Apple processing, assign a tester group, or verify physical installation. Version 1.2.4 (8) has already been delivered and is Testing in the Personal internal group; do not repeat that upload. The current state and registered destinations are in [release status](../Release/STATUS.md) and [project-destinations.json](../project-destinations.json).

## Runtime and branding

The phone supports native library navigation, whole-library search, Smart Shuffle, an expanded Aura player, queue/repeat/AirPlay, offline listening, and favorite changes that return to the Mac. Creating, importing, and Remix remain Mac features. The phone follows System/Light/Dark appearance and Dynamic Type.

The approved blue lyre, gold maker mark, and fonts are included. iPhone icons are opaque 1024×1024 RGB with distinct light/dark compositions, regenerated by `scripts/prepare-icon.sh`. Compatibility resource names do not control the displayed brand.

The current transfer uses a user-selected shared provider folder and offline `PhoneLibrary` cache. Existing Wisp-named folders remain valid. It does not use an app-specific iCloud entitlement or independently export the complete library from the phone. Mac-off PC backups and restorable iPhone exports remain future implementation with confirmed personal-data scope; see [RELEASE_PROMPT.txt](../RELEASE_PROMPT.txt).

The target declares background audio and opening documents in place. File sharing is disabled to avoid another empty app folder. It does not request Music control, tracking, camera, microphone, or photo-library permission. Recheck the privacy manifest and export-compliance declaration if data access or encryption changes. Simulator checks do not prove physical device behavior.
